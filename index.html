Main-conference research tracks only. Every date read from the venue's own call for papers or HotCRP, then re-checked against the same source. Timezones are per-date — MICRO publishes EDT, not AoE. Where a venue publishes no clock time the counter runs to end of day and says so; it is never invented. Closed cycles sort to the bottom. The countdown is timezone-independent — a duration is the same everywhere, so the selector only changes which calendar date is printed. Dates with no published clock time always show as published, since there is no instant to convert.
